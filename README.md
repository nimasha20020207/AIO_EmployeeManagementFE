# AIO Employee Management

A responsive employee management dashboard built with Vue 3, TypeScript, and Vite.

## Features

- At-a-glance team metrics and department overview
- Employee directory with search, department and status filters
- Add, edit, and remove employees
- Responsive layout for desktop and mobile screens
- Local sample data; no backend connection is required

## Getting started

```sh
npm install
npm run dev
```

## Scripts

- `npm run dev` — start the Vite development server
- `npm run build` — type-check and create a production build
- `npm run preview` — preview the production build locally

Employee changes are held in browser memory and reset when the page is refreshed.
